Hoseline

Прослушивание групп BrandMeister в браузере. По умолчанию выбрана всемирная группа TG91.

Слушать TG91 в Hoseline ↗

Официальный плеер откроется в отдельной вкладке. Для звука нажмите Player / Play.

Чтение Last Heard…

    Hoseline воспроизводит звук на устройстве, в браузере которого открыт плеер. Список ниже плеера сверяется отдельно с журналом Raspberry: звук в Hoseline сам по себе не подтверждает приём на хотспоте. Прослушивание не меняет подписки хотспота.
