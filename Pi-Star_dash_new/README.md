# PSTAR Dashboard New — локальный прототип

[Отчёт о проверках](docs/TEST-REPORT.md) · [Hoseline и сравнение с Last Heard на `pistar3`](http://192.168.210.194:8789/hoseline.html) · [Полевой тест TG91](docs/RF-ACCEPTANCE.md)

Панель на Svelte 5 и TypeScript. На машине разработки используются демонстрационные данные. На пилотной [Raspberry Pi `pistar3`](http://192.168.210.194:8789/) та же сборка читает реальные данные с `/api/status`. [Нативные настройки](https://192.168.210.194:8788/manage/) вынесены на отдельный HTTPS-сервис с авторизацией. [План переезда](docs/MIGRATION.md) и [разбор оригинального PHP](docs/PARITY.md).

## Запуск

Нужны Node.js 22 и npm. В каталоге проекта:

```sh
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173/** на машине разработки. Сервер слушает только loopback. `Ctrl+C` завершает его.

## Что посмотреть

- Переключите штатный режим на потерю мастера: состояние модема должно остаться нормальным.
- Выберите только `RF` в Last Heard. Фильтр должен сохраняться при обновлении данных.
- Сравните тихий эфир с недоступным журналом: отсутствие вызовов и отсутствие данных — разные состояния.
- При недоступном API последний успешный снимок остаётся на экране с признаком устаревания.

## Данные прототипа

`src/data.ts` содержит тип `Snapshot` и единственную точку получения данных —
`fetchSnapshot()`. `UpdatedAt` обозначает время снимка, а `Modem.At` и
`Master.At` — время подтверждающего события. При повторном обновлении снимка
эти три времени не обязаны совпадать. В строке Last Heard отсутствие
`BER`, `Loss` или `Duration` означает «не передано»; числовой ноль —
действительное измерение.

## Проверки

```sh
npm test
npm run check
npm run build
```

`dist/` — статические файлы веб-интерфейса. Для просмотра собранной версии: `npm run preview` и `http://127.0.0.1:4173/`. Сборка не создаёт образ ОС и не развёртывает панель на плате.

Проверки пилота: `ssh pistar3 'python3 -' < qa/board.py` (на плате) и
`python3 qa/full_ui.py --url http://192.168.210.194:8789/ --expect live` (браузер).
`npm run package:stock` собирает отдельно каталог для штатного PHP-сервера Pi-Star:
старые URL остаются на месте, каталог Svelte открывается по `/operator/`.
Это не пакет для статического HTTP-сервера на порту 8789.
